# Phase 3 report - build-supervisor (operator, PROTECTED guard, queue)

- New `lib/operator.sh` modes: `resume` (DIED/STALLED: kill leftovers, `## RESUME DIRECTIVE (auto, resume N/2, <ET>) - read first` under the plan title = continue from the build log, do not redo committed phases; relaunch; cap 2 then ESCALATE), `triage` (STOPPED), `gate` (DONE merge gate), `post-merge`, `escalate`.
- Judgment = headless `claude -p` with `--append-system-prompt-file templates/operator-prompt.md`, `--json-schema` decision, `--no-session-persistence`, read-only tool allowlist (Read/Glob/Grep + gh pr view/checks/diff, git log/show/diff, jq, ls/cat/head/tail/find/wc); Edit/Write/push/merge/commit/rm disallowed; 40 min watchdog. All actions are shell, never the model.
- New `templates/operator-prompt.md`: Jim's operating standard (approve as-proposed + obvious additions, plan = contract, evidence beats claims, Codex P1 routed to operator, one-line questions), PROTECTED list (spend/tier, credentials, Audrey live lists/curations + customer-facing sends, deletion beyond named throwaways, unqueued launches, "Jim decides", any uncertainty), triage + merge-gate procedures (open every screenshot, parse JSON, >=10 row spot-check, CI + Codex).
- Deterministic guards over the model: triage escalates if protected_hit, not in_scope, no decision, approve-without-directive, or the report contains "Jim decides"; auto-approvals capped at 3 per build (loop guard, beyond the plan's caps). Gate PASS is downgraded to FAIL if any criterion is unmet or ci_green is false; rejections capped at 2 then ESCALATE.
- Gate PASS: log + commit + push decision, wait for checks green again (<=15 min), kill builder + watcher, prune worktree, `gh pr merge --squash --delete-branch`, then post-merge. Any merge failure escalates.
- Post-merge / queue: `~/.walkaway-cli/queue/<repo-basename>.txt` (ordered plan paths, # comments ok). Head is removed before launching (no relaunch loops), held if another non-merged build in the same repo is registered (one builder per repo; repos parallel). Default branch checked out + ff-pulled first so walkaway's base guard passes.
- Every decision appended to `handoff/operator-log-<feature>.md` and committed with `git commit --no-verify -- <log> [<plan>]` (only those paths; builder work is never swept in).
- Registry gains `worktree` so relaunches of worktree builds pass `--worktree` again.
- Sanity: `operator.sh escalate` on a temp build -> registry ESCALATED, operator log committed, one ntfy line (priority high) recorded.
- Gates: shellcheck -S warning rc=0; parse tests 7/7. Files: lib/operator.sh (new), templates/operator-prompt.md (new), lib/registry.sh, walkaway.sh.
